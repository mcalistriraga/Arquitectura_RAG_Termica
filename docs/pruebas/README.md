# Pruebas del Proyecto

## Descripción

Esta carpeta contiene el registro de pruebas realizadas durante el desarrollo de la arquitectura RAG.

Su objetivo es conservar evidencia de experimentos, validaciones y resultados obtenidos durante la implementación de los distintos componentes del sistema.

Los documentos aquí almacenados representan el estado del proyecto en la fecha indicada por cada archivo y complementan la información resumida en `06_pruebas_y_validacion.md`.

## Convención de nombres

Los archivos utilizan el formato:

YYYY-MM-DD_descripcion.md

Ejemplo:

2026-07-20_prueba01_modelo_qwen2.5-coder-1.5b.md

## Alcance

Las pruebas pueden corresponder a:

- validación de modelos LLM;
- backend LOCAL;
- backend CLOUD;
- generación de embeddings;
- supervisión térmica;
- rendimiento;
- integración de componentes.

Los resultados aquí documentados representan evidencia histórica y no necesariamente reflejan el estado actual del proyecto.
